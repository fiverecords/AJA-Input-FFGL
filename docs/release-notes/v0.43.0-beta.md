Low-latency live input from AJA capture cards (KONA, Corvid, Io) for
Resolume Arena and Avenue 7 on Windows, as an FFGL source plugin. It
shows up in Resolume as **AJA Input**.

**This is the first public release.** It is tested on an AJA KONA X,
where it ran a live show for hours with two inputs at different
resolutions. It is a **beta** because the other AJA cards, 4K over
several FrameStores (quad-link, 4K HDMI) and HDR signalling have not
been tried on hardware yet. Reports from any card are very welcome:
please use the issue template and include the log lines it asks for.

## Install

1. Close Resolume.
2. Copy `AJAInput.dll` from the ZIP to
   `Documents\Resolume Arena\Extra Effects\` (or `Resolume Avenue`).
3. Install AJA's driver for your card (AJA Desktop Software; the plugin
   is built against SDK 18.0 and was developed with driver 18.0).
4. Start Resolume: **AJA Input** is among the Sources. Pick the Device
   and the Input in the clip.

## Highlights

- Interrupt-driven capture of the newest complete frame, page-locked
  DMA and an off-thread GPU upload; optional Low Latency Mode.
- One capture per input, shared by every clip that shows it.
- SDI 1-8, HDMI 1-4, experimental quad-link and HDMI 4K on cards without
  12G routing; 4K on one 12G cable on the KONA X family, KONA 5 12G
  firmwares and Corvid 44 12G.
- YADIF de-interlacing; BT.601 / BT.709, PQ and HLG (tone-mapped to SDR)
  with Auto following the source's signalling.
- Resize (Fit, Fill, Stretch, Original), No Signal (Black, Transparent,
  Hold Last Frame), a Format readout and a stats overlay.

## Known limitations

- Windows only; no embedded audio (FFGL has no way to pass audio to the
  host).
- Cards other than the KONA X are untested on hardware.
