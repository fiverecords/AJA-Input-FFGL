# Development history (before 0.43)

AJA Input was developed privately for one AJA KONA X, under the working
name `konax-ffgl`, before its first public release (0.43). These
documents are that history, kept as they were written: names, file paths
and parameters in them are those of the time, and they refer to
versions that were never published. The version tags in the code's
comments (`v0.40: ...`) point here.

- [CHANGELOG_0.1-0.42.md](CHANGELOG_0.1-0.42.md): every private version.
- [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md): the design record per
  milestone (what was tried, measured and decided, and why).
- [LATENCY_STRATEGY.md](LATENCY_STRATEGY.md): how the latency was
  brought below a frame.
- [AUDIT_v0.39.md](AUDIT_v0.39.md): a full code audit and its fixes.
